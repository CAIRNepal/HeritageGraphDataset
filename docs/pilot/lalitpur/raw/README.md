# Raw responses (pilot, Lalitpur District)

Saved exactly as returned; the query and the retrieval time (UTC) are next to each response.

| file | source | licence and attribution |
|---|---|---|
| `overpass_query.overpassql`, `overpass_response.json`, `overpass_retrieved_at.txt` | OpenStreetMap via the Overpass API (overpass-api.de), one request | © OpenStreetMap contributors, Open Database License 1.0, <https://www.openstreetmap.org/copyright> |
| `wikidata_query.rq`, `wikidata_response.json`, `wikidata_retrieved_at.txt` | Wikidata Query Service | CC0 1.0 |

Requests identified themselves with the User-Agent `HeritageGraphDataset-pilot/0.1 (CAIR-Nepal research; https://github.com/CAIRNepal/HeritageGraphDataset)`.
The first Overpass attempt hit a busy server (HTTP 502) and was not repeated in a loop; the saved response is from a
single later request.
